# Шаблоны многостраничника

Шапка, подвал, корзина и форма лежат по одному разу, страницы склеиваются
из них сборщиком `инструменты/собрать.py`. Правится один кусок — меняются
все страницы сразу.

## Как пользоваться

1. Скопировать эту папку в проект как `_шаблоны`.
2. Заполнить `данные.json` — название, телефон, адрес, почта, реквизиты.
3. Править куски и страницы, **не** собранные html в корне проекта.
4. Собрать: `python инструменты/собрать.py --проект "папка проекта"`.
   Во время работы удобно держать `--следить`.

```
_шаблоны/
  данные.json          общие подстановки
  куски/голова.html    <head> целиком, с {{заголовок}} и {{описание}}
  куски/шапка.html     шапка с меню
  куски/подвал.html    подвал
  куски/форма.html     блок заявки
  куски/корзина.html   панель корзины — только для магазина
  куски/товары.html    карточки каталога, их пишет каталог.py
  куски/скрипты.html   подключение скриптов и закрывающие теги
  страницы/index.html      первый экран, выгоды, заявка
  страницы/каталог.html    каталог с фильтрами и корзиной
  страницы/доставка.html   доставка, оплата, вопросы
  страницы/контакты.html   адрес, телефон, карта, заявка
```

## Два обозначения

```html
<!-- вставить: шапка -->     подставить _шаблоны/куски/шапка.html
{{телефон}}                  значение из данные.json
```

Свои значения страницы — блоком в самом верху файла:

```html
<!-- страница
заголовок: Каталог — {{название}}
описание: Что есть в наличии: корма, игрушки, лежанки.
адрес: каталог.html
-->
```

`адрес` — имя собранного файла. Если хотите латинские адреса страниц
(`catalog.html`, `contacts.html`), меняется только эта строка и ссылки
в `шапка.html` и `подвал.html`.

## Что сборщик делает сам

- проставляет `aria-current="page"` пункту меню текущей страницы;
- пишет в начало файла пометку, что он собран и править его не надо;
- перечисляет незакрытые подстановки и внутренние ссылки в никуда.

## Чего не делать

- Не править собранные `index.html`, `каталог.html` и прочие в корне
  проекта: следующая сборка затрёт правки.
- Не копировать один и тот же кусок в две страницы руками — для этого
  всё и затевалось.
