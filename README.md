# МосЭплТорг — макет сайта магазина техники Apple

Статический сайт магазина новой и б/у техники Apple, DJI и Dyson в Москве.
Без фреймворков, без сборщиков, без внешних запросов: HTML, CSS и несколько
небольших скриптов на обычном JavaScript.

**Клиенту читать [ПРОЧТИ МЕНЯ.md](ПРОЧТИ%20МЕНЯ.md)** — там про то, что уже
работает, что в макете нарочно не настоящее и какие данные ещё нужны.

## Что внутри

48 страниц:

| Раздел | Страница |
|---|---|
| Главная | `index.html` — слайдер баннеров, бегущая строка, категории, Trade-in, отзывы, заявка |
| Каталог | `каталог.html` — 40 позиций, боковой фильтр по цене, типу, бренду и состоянию |
| Товары | `товар-*.html` — 40 страниц: галерея с увеличением, характеристики, похожие |
| Сравнение | `сравнение.html` — до четырёх товаров в одной таблице |
| Trade-in | `trade-in.html` |
| Доставка | `доставка.html` |
| Контакты | `контакты.html` — с картой Яндекса |
| Служебное | `privacy.html`, `404.html`, `robots.txt`, `sitemap.xml` |

Работает без сервера: корзина и сравнение живут в `localStorage`, данные для
таблицы сравнения вшиты в страницу, а не подгружаются запросом.

## Структура

```
assets/products/     снимки товаров: <id>-N.webp и <id>-1-min.webp для каталога
assets/banners/      баннеры первого экрана, широкие и мобильные
общее/css/           скелет: base, blocks, effects, ui, ui-plus
общее/js/            скрипты: корзина, сравнение, галерея, ленты, баннеры, просмотр
theme.css            тема проекта: цвета, шрифты и все его собственные блоки
шрифты/              Manrope и Inter в woff2
товары.json          единственный источник правды по каталогу
_шаблоны/            куски страниц и сборщик — из них собираются файлы в корне
```

Собранные `.html` в корне руками не правят: их перезапишет следующая сборка.
Правятся `_шаблоны/` и `товары.json`.

## Как пересобрать

```bash
python фото-товаров.py
```

```bash
python характеристики.py
```

```bash
python варианты.py
```

```bash
python собрать-каталог.py
```

```bash
python собрать-товары.py
```

```bash
python инструменты/собрать.py --проект .
```

Первые три нужны, только когда меняются снимки, характеристики или объёмы
памяти. Обычная правка цен — это `товары.json` и три последние команды.

Проверить макет целиком (поднимает сервер, обходит все страницы, смотрит
прокрутку на 320/375/1280, размеры кнопок, контраст, битые ссылки):

```bash
python инструменты/проверка.py --проект . --отчёт отчёт.md
```

## Локальный просмотр

```bash
python -m http.server 8000
```

Открывать по `http://localhost:8000`, а не файлом: часть страниц использует
относительные пути и карту Яндекса.

## Публикация на GitHub Pages

Репозиторий готов: рядом лежит `.nojekyll`, иначе Pages прогнал бы сайт через
Jekyll и выбросил папку `_шаблоны`. Включите Pages в настройках репозитория
(ветка `main`, папка `/`) — сайт поднимется как есть.

Перед публикацией **настоящего** сайта, а не витрины:

1. убрать `<meta name="robots" content="noindex, nofollow">` из `_шаблоны/куски/голова.html`;
2. отключить демо-режим формы — убрать `общее/js/demo.js` из `_шаблоны/куски/скрипты.html`;
3. вписать рабочую почту в `общее/send.php` (нужен хостинг с PHP — на Pages форма
   работать не будет, там остаётся демо-режим);
4. заполнить данные из списка в `ПРОЧТИ МЕНЯ.md`.

Всё это переключает `инструменты/сдача.py` из заготовок.
